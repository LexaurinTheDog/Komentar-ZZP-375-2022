# Komentář k zákonu č. 375/2022 Sb., o zdravotnických prostředcích a diagnostických zdravotnických prostředcích in vitro

Otevřený komentář k zákonu o zdravotnických prostředcích a diagnostických zdravotnických prostředcích in vitro — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; adaptace nařízení MDR a IVDR, SÚKL, povinnosti výrobců a distributorů, klinické zkoušky, předepisování a výdej, používání, servis, vigilance, dozor nad trhem a přestupky.
